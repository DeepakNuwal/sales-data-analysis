# 🧮 Sales Data Analysis using Python

This project analyzes a Superstore dataset to uncover sales performance, profit trends, and product insights using Python.

## 🧰 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Steps
1. Data Cleaning and Preprocessing  
2. Exploratory Data Analysis (EDA)  
3. Visualization of Key Insights  

## 📈 Key Insights
- Technology category generates the most revenue.  
- The West region is the most profitable.  
- Sales increase during Q4 every year.  

## 🚀 How to Run
1. Clone the repo  
2. Run `pip install pandas matplotlib seaborn numpy`  
3. Open `sales_data_analysis.ipynb` in Jupyter Notebook  
4. Run all cells  

## 📂 Dataset
Superstore dataset: [Kaggle Link](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
